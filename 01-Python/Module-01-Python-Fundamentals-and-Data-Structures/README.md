- 1.2 Input and Output (`print()`, `input()`)

## Lesson notes added so far
- Day 01–03: Variables, data types, `print()`, f-strings, `input()`, type conversion, arithmetic, comparison and logical operators.

## Learning rule
Understand the concept, dry-run the code, type it yourself, modify values, deliberately break it, and fix the error.

## DevOps connection
Examples use server metrics, thresholds, service names and reports so Python skills progressively connect to automation and later Agentic DevOps work.
