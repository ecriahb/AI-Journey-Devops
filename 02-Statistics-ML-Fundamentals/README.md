# Phase 02 — Statistics + ML Fundamentals

**Goal:** Understand the minimum statistics and ML foundation required to work confidently with AI systems.

### Modules
- Descriptive statistics, probability and distributions
- Correlation and basic statistical reasoning
- ML concepts and workflow
- Regression and classification
- Logistic Regression
- Train/test split and evaluation
- Confusion matrix, precision, recall, accuracy
- Overfitting and underfitting
- Supervised vs unsupervised learning
- scikit-learn basics, K-Means and PCA concepts

**Source:** Prepzee Modules 6–10.

**Rule:** Learn concepts and practical interpretation; do not spend disproportionate time on advanced ML mathematics.
