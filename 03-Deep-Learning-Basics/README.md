# Phase 03 — Deep Learning Basics

**Goal:** Understand neural networks well enough to understand modern AI and transformers.

### Modules
- Neural network fundamentals
- ANN, CNN and RNN concepts
- Tensors and computation basics
- TensorFlow/Keras and PyTorch orientation
- Training, loss, optimization and inference
- NLP and image-processing foundations

**Source:** Prepzee Modules 11–15.

**Depth:** Conceptual + small hands-on exercises. Advanced research-level DL is not the target.
