# Python Lesson 03 — Practice

## Practice 1 — Variables and Types
Create:
- an integer variable
- a float variable
- a string variable

Print each value and its type using `print()` and `type()`.

## Practice 2 — Case Sensitivity
Create:
```python
name = "Alex"
```
Then try `name` and `Name` separately and observe the result.

## Practice 3 — Condition
Create an `age` variable and write an `if` statement that prints a message when age is 18 or above.

## Practice 4 — For Loop
Create:
```python
fruits = ["apple", "banana", "cherry"]
```
Use a `for` loop to print each fruit.

## Practice 5 — Indexing
Using the same list:
1. Print the first item.
2. Print the second item.
3. Print the last item using negative indexing.

## Practice 6 — Modify
Change `apple` to `blueberry` using its index.

## Practice 7 — List Methods
Starting with a fruits list:
1. Add `orange` using `append()`.
2. Remove one item using `remove()`.
3. Sort the list using `sort()`.
4. Sort it in reverse order.

## Practice 8 — Slicing
Given:
```python
numbers = [10, 20, 30, 40, 50]
```
Try:
```python
numbers[0:2]
numbers[1:4]
numbers[:3]
numbers[2:]
numbers[::-1]
```
Write down the output of each.

## Practice 9 — Reverse Slicing
Using the same list, experiment with negative steps:
```python
numbers[4:1:-1]
numbers[4:0:-2]
numbers[::-1]
```
Understand how `start`, `stop`, and `step` change the result.

## Practice 10 — Error Practice
Intentionally create and identify:
- an indentation error
- a syntax error by omitting a required colon
- a name error by using an undefined variable

Then fix each error.
