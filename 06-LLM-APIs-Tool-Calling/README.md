# Phase 06 — LLM APIs + Tool Calling

**Goal:** Move from using AI interactively to building software around AI.

### Modules
- REST / HTTP / JSON fundamentals
- API authentication and environment variables
- LLM provider APIs
- Request/response lifecycle
- Error handling and retries
- Structured output enforcement
- Tool schemas and argument validation
- Tool request vs tool execution
- Single tool call vs agent loop

**Source:** Agentic AI Module 1/API material, with Prepzee API coverage used as supporting foundation.

**Deliverable:** Python application that calls an LLM and safely invokes a read-only DevOps tool.
