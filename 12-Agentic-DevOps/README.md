# Phase 12 — Agentic DevOps

**Goal:** Combine existing DevOps expertise with agents, tools, RAG, MCP, LangGraph and production controls.

### Modules
- DevOps incident investigation agent
- CI/CD failure analysis
- Terraform investigation assistant
- AKS troubleshooting agent
- Azure Monitor / logs / metrics investigation
- Evidence-grounded RCA
- Remediation recommendation
- Human approval before risky actions
- Least privilege and tool allowlists
- Auditability, observability and production safety

**Target architecture:** Collect trusted signals → analyze → RCA → recommend fix → human approval → execute approved action.

**This is the specialization phase.**
