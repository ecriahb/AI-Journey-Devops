# AI Journey for DevOps

A structured learning repository for the **GenAI and ML Feb** course and the user's progression from Python → Statistics → Machine Learning → Deep Learning → AI/GenAI → MLOps.

## Course Structure

- 1 Module
- 50 Lessons
- Each lesson has its own folder.
- Transcripts provided by the learner will be converted into structured study notes and committed to the corresponding lesson folder.

## Standard Lesson Content

Each completed lesson will normally contain:

- `transcript.vtt` or source transcript
- `notes.md` — easy Hinglish + professional technical notes
- `quick-revision.md` — short revision sheet
- `interview-questions.md` — interview-focused questions
- `practice.md` — exercises/homework when supported by the transcript
- `README.md` — lesson overview and status

> Source-first rule: lesson notes are based primarily on the instructor transcript. Any additional clarification will be clearly marked as additional context.
