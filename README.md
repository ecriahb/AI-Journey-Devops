## 📝 Standard Lesson Structure

For every lesson for which a transcript is provided, the corresponding lesson folder will contain:

```text
Lesson/
├── README.md
├── transcript.vtt
├── notes.md
├── quick-revision.md
├── interview-questions.md
└── practice.md
```

Files will be added only when relevant content is available; no unnecessary placeholder material will be created.

## 🎯 Notes Standard

Every transcript will be converted into:

1. Lesson Overview
2. Instructor Concepts
3. Concept-by-Concept Explanation
4. Important Definitions
5. Examples / Code
6. Formulas / Diagrams where applicable
7. ⭐ What You MUST Know
8. 🟡 What You Can Keep Light
9. DevOps / MLOps Connection
10. Interview Questions
11. Practice / Homework
12. Quick Revision Sheet

### Source-first rule

The instructor transcript is the primary source. The notes will preserve the instructor's terminology, organization and level of detail. Any additional explanation or clarification will be explicitly marked as **Additional Context**.
