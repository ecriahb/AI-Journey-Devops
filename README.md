### Important

- Each subject exists **only once** at repository root.
- Course modules are nested inside their subject.
- Dated class folders are preserved under the relevant subject's `Lessons/` area until each lesson is mapped from its actual transcript/content to a specific curriculum module. No lesson-to-module mapping is guessed.
